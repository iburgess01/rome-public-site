Personal tools / Newsletter assistant

A little less inbox.
A little more perspective.

Rome turns its owner’s newsletters into a concise, personalised reading digest.

Built on OpenClaw, Rome connects to the owner’s Google account to read selected newsletters and a preferences sheet. It uses AI to organise the stories, then saves the digest in the owner’s private Rome workspace.

The workflow

From newsletters
to a useful read.

  1. Read selected newsletters

    Find unread messages in the newsletter label and retrieve the selected messages’ text, headers and links.

  2. Summarise with context

    Use interests from a Google Sheets preferences document and OpenAI models to select and summarise relevant stories.

  3. Save, then mark as read

    Save a digest and processing record, verify the saved files, then mark only the successfully processed messages as read.

Account access

For one person.

Rome’s Google integration is for its owner’s personal use. This website provides information about the integration; it has no public sign-up or mailbox connection.

The newsletter workflow reads Google Sheets and Drive information without editing Google files. It does not send email, create drafts, archive messages or delete messages.

Newsletter content and preferences used to generate a digest are sent to OpenAI for AI processing. Digests and processing records are kept in Rome’s private storage.
